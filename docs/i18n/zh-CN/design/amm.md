# AMM

## 范围

本文对应 [`src/AMM/AMM.sol`](../../src/AMM/AMM.sol)。合约演示恒定乘积公式的虚拟储备计算，不持有或转移任何一种资产。

## 行为

- `addLiquidity` 增加两个公开储备值。
- `swapAForB` 和 `swapBForA` 使用 `amountIn * reserveOut / (reserveIn + amountIn)` 计算输出，并更新虚拟储备。
- `priceA` 返回当前储备比例，以 `1e18` 为精度。

## 假设与限制

- 储备是调用者提供的记账数字，不是代币余额。任何人都能不存入资产而增加储备。
- 兑换不收取输入代币，也不交付输出代币。因此事件与返回值不代表已结算交易。
- 没有 LP 份额、手续费、最小输出检查、截止时间或预言机保护。`priceA` 是即期比率，不适合作为价格预言机。
- 储备不平衡或输入很小时可输出零。Solidity 的检查算术仍会在溢出时回滚。

这个合约仅演示储备计算，不是交易所、做市商或生产 AMM，不应用于托管资产。
