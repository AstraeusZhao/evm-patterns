# PullPaymentVault

`PullPaymentVault` 是仓库中的早期可执行模式，以小型记账金库演示安全提取边界，不引入外部依赖。

## 行为

- 任何人可存入 ETH 并获得内部记账额度。
- 用户只能提取自己的已记录额度。
- 所有者可暂停和恢复存入与提取。
- 所有权可转移，但所有者没有管理员提取资金的路径。

## 安全特性

- 减少额度前先检查余额。
- 接收者调用前减少余额，遵循检查、状态更新、交互（CEI）。
- 重入锁阻止接收者合约在 ETH 转账期间再次进入 `withdraw`。
- 自定义错误明确失败路径，避免使用字符串错误。
- 暂停是停止操作的开关，不是恢复机制；用户须等待所有者解除暂停后提取。

## 信任假设与限制

- 信任所有者管理暂停与所有权转移。
- 接收者拒绝 ETH 会使转账失败，提取回滚，用户额度保持不变。
- 没有升级、收费、代币支持或紧急清扫机制。
- 此示例用于学习和审阅，未经过独立安全审计，不用于托管生产资金。

## 测试覆盖

Foundry 测试覆盖正常存入和提取、所有者暂停、暂停时存入和超额提取保护。
