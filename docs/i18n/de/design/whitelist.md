# Whitelist

Vom Eigentümer verwaltete Positivliste mit einem Beispiel für einen zugangsbeschränkten Verkauf.

## Eigenschaften

- Nur der Eigentümer kann Konten hinzufügen oder entfernen; wiederholte Aktionen werden geprüft.
- `onlyWhitelisted` beschränkt nachgelagerte Funktionen. Der Verkauf lehnt nicht gelistete Konten ab.

## Vertrauensannahmen

Der Eigentümer bestimmt die Teilnahme. Ein böswilliger Eigentümer kann beliebige Konten zulassen oder alle ausschliessen.
