# PullPaymentVault

`PullPaymentVault` 是倉庫中的早期可執行模式，以小型記賬金庫演示安全提取邊界，不引入外部依賴。

## 行為

- 任何人可存入 ETH 並獲得內部記賬額度。
- 用戶只能提取自己的已記錄額度。
- 所有者可暫停和恢復存入與提取。
- 所有權可轉移，但所有者沒有管理員提取資金的路徑。

## 安全特性

- 減少額度前先檢查餘額。
- 接收者調用前減少餘額，遵循檢查、狀態更新、交互（CEI）。
- 重入鎖阻止接收者合約在 ETH 轉賬期間再次進入 `withdraw`。
- 自定義錯誤明確失敗路徑，避免使用字符串錯誤。
- 暫停是停止操作的開關，不是恢復機制；用戶須等待所有者解除暫停後提取。

## 信任假設與限制

- 信任所有者管理暫停與所有權轉移。
- 接收者拒絕 ETH 會使轉賬失敗，提取回滾，用戶額度保持不變。
- 沒有升級、收費、代幣支持或緊急清掃機制。
- 此示例用於學習和審閱，未經過獨立安全審計，不用於託管生產資金。

## 測試覆蓋

Foundry 測試覆蓋正常存入和提取、所有者暫停、暫停時存入和超額提取保護。
