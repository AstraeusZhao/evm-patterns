# AMM

## 範圍

本文對應 [`src/AMM/AMM.sol`](../../src/AMM/AMM.sol)。合約演示恆定乘積公式的虛擬儲備計算，不持有或轉移任何一種資產。

## 行為

- `addLiquidity` 增加兩個公開儲備值。
- `swapAForB` 和 `swapBForA` 使用 `amountIn * reserveOut / (reserveIn + amountIn)` 計算輸出，並更新虛擬儲備。
- `priceA` 返回當前儲備比例，以 `1e18` 為精度。

## 假設與限制

- 儲備是調用者提供的記賬數字，不是代幣餘額。任何人都能不存入資產而增加儲備。
- 兌換不收取輸入代幣，也不交付輸出代幣。因此事件與返回值不代表已結算交易。
- 沒有 LP 份額、手續費、最小輸出檢查、截止時間或預言機保護。`priceA` 是即期比率，不適合作為價格預言機。
- 儲備不平衡或輸入很小時可輸出零。Solidity 的檢查算術仍會在溢出時回滾。

這個合約僅演示儲備計算，不是交易所、做市商或生產 AMM，不應用於託管資產。
